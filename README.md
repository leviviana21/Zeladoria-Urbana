# Zeladoria Urbana API (.NET 10)

API desenvolvida em C# com .NET (arquitetura backend para a solução de Zeladoria Urbana - PIM), focada em gerenciar e otimizar processos de zeladoria e manutenção urbana. Este projeto faz parte do meu portfólio de desenvolvimento de software e foi construído com foco em boas práticas de arquitetura de APIs RESTful.

---

## 🚀 Tecnologias Utilizadas
* **Linguagem:** C# (.NET 10)
* **Frameworks/Bibliotecas:** ASP.NET Core, Entity Framework Core, MySQL, Swagger/OpenAPI, JWT Bearer Authentication
* **Arquitetura:** API RESTful orientada a serviços

---

## 📂 Estrutura do Projeto
* `ZeladoriaUrbana.API/`: Projeto principal da API contendo os controladores, configurações, contextos de banco de dados e dependências.
* **Scripts:** Arquivos de configuração para ambiente de desenvolvimento e produção.
